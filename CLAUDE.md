## Build & Dev Commands

- `npm run dev` — Start Vite dev server with HMR
- `npm run build` — Production build to `dist/`
- `npm run preview` — Preview production build
- `npm run lint` — ESLint check (flat config, `eslint.config.js`)

No test framework is configured.

## Environment Setup

Copy `.env.example` to `.env` and fill in Firebase credentials (see file for required `VITE_FIREBASE_*` variables). The app will not function without valid Firebase config.

## Architecture Overview

**React 19 + Vite SPA** with Firebase Auth/Firestore backend. Tailwind CSS for styling. No TypeScript — all source is `.js`/`.jsx`.

### Routing & Pages (`src/pages/`)

- `LoginPage` / `SignupPage` — Firebase email/password auth
- `DashboardPage` — Lists user's saved projects from Firestore
- `EditorPage` — Main workspace; loads a project by `?project=<id>` query param

Auth state drives route guards in `App.jsx`. Session persistence (`browserSessionPersistence`) means auth clears on tab close.

### State Management

Single Zustand store (`src/store.js`) organized as composable slices:

- **Level slice** — multi-floor support, site dimensions, grid snap, units, textures, compass/time-of-day
- **Wall slice** — wall CRUD, multi-select, wall splitting at intersections, openings (doors/windows), paint/texture per side
- **Objects slice** — furniture, stairs, pillars, room labels; all per-level
- **History slice** — undo/redo (30-step limit), named version snapshots, project load/save/export, template loading

All mutations call `saveHistory()` before state changes for undo support. The store also owns `updateStability()` which checks structural support across levels.

### Editor Components (`src/components/`)

- **TwoDEditor** — Konva (`react-konva`) canvas: wall drawing, furniture placement, drag/resize, grid snap, angle snap, alignment guides, collision detection, room detection overlay, multi-select, context menus, PDF/PNG/JSON export
- **ThreeDViewer** — Three.js via `@react-three/fiber` + `@react-three/drei`: real-time 3D from 2D data, textured walls with per-side materials, floor/ceiling per room, roof generation, day/night lighting, first-person mode (WASD + pointer lock)
- **AssetLibrary** — Sidebar drag source for furniture, structural, and annotation items
- **SiteConfigModal** — Initial site dimension setup and template selection
- **CostEstimator** — Calculates costs from walls/furniture/openings
- **CloudPanel** — Firestore save/load UI, share links
- **OnboardingTour** — First-visit walkthrough overlay
- **Toast** — Global toast notification system (context-based)
- **ErrorBoundary** — Top-level React error boundary

### Utilities

- `src/utils/geometry.js` — Line intersection, distance-to-segment, angle snapping, alignment guides, collision detection, structural stability checking, THREE.Shape generators for floors/roofs
- `src/utils/roomDetection.js` — Graph-based algorithm that finds closed polygons from wall segments using angle-based traversal (left-turn rule), computes area via shoelace formula
- `src/data/templates.js` — Pre-built floor plan templates (studio, 1BHK, 2BHK, villa)
- `src/constants.js` — All config: dimensions, colors, textures, materials, units, presets, keyboard shortcuts, paint colors

### Firebase Layer (`src/firebase.js`)

Exports auth functions (`signUp`, `signIn`, `signOut`, `onAuthChange`) and Firestore CRUD (`saveProject`, `loadProject`, `listProjects`, `deleteProject`). Projects are stored in a `projects` collection scoped by `user_id`.

### Key Conventions

- Pixel coordinates are the source of truth; unit conversion (ft/m) is display-only via `CONFIG.UNITS`
- Wall objects carry `start`/`end` points, `thickness`, `height`, per-side colors/textures, and an `openings` array
- Every entity has a `levelId` for multi-floor filtering
- IDs are UUIDs generated by the `uuid` package
- ESLint rule: `no-unused-vars` ignores variables starting with uppercase or underscore (`varsIgnorePattern: '^[A-Z_]'`)
